# 42 Lisboa — Piscine (Agosto de 2021)

Este repositório reúne exercícios e trabalhos desenvolvidos durante a **Piscine da 42 Lisboa**, realizada em agosto de 2021.

A Piscine é um período intensivo de aprendizagem e resolução de problemas, focado nos fundamentos de programação, trabalho autónomo e colaboração entre participantes.

## Conteúdos

- `shell/` — exercícios introdutórios de Shell
- `c00_entrega/` e `c01/` a `c08/` — exercícios progressivos em C
- `RUSH/`, `RUSH01/` e `RUSH02/` — trabalhos realizados em grupo durante a Piscine

## Tecnologias

- C
- Shell
- Git
- Ambiente Unix/Linux

## Nota

O código representa o meu percurso de aprendizagem durante a Piscine e é mantido como registo académico.
